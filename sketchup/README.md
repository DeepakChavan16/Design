House Design – SketchUp 3D Model
📌 Project Overview
This project contains a 3D house model created using SketchUp. The model (house.skp) can be opened in SketchUp to explore the house design, inspect its geometry, and make further modifications.

The repository is intended to showcase a 3D architectural design project and provide the source model for viewing or continued development.
🏠 Project File
- house.skp — The SketchUp project file containing the 3D house model.
🛠️ Software Used
- SketchUp — 3D modeling and architectural design software.
- Git and GitHub — Version control and project hosting.
🚀 How to Open the Project
1. Download or clone this repository to your computer.
2. Install and open SketchUp.
3. In SketchUp, select File → Open.
4. Choose house.skp.
5. Use the Orbit, Pan, and Zoom tools to explore the model.
Note: Compatibility may depend on the SketchUp version used to save the file. If the file does not open, try a compatible SketchUp version or ask the author to export it in a supported format.
